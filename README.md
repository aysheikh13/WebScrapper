# WebScrapper

## 1: About
Scrape's websites for links via extracting and parsing HTML data on HTTPS websites using SLL and TCP/IP

## 2: Instructions

Ensure the usage and implementation of the Boost/Beast library that enables networking protocols and the usage of web sockets to obtain HTML data.

Also, include the flag -lss when compiling as G++ or using an ordinary compiler like onlineGDB.
